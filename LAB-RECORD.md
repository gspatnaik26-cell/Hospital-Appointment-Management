
# LAB RECORD

## Lab Experiment 2

**Title:** Refactor to Engineering-Grade HTML (M1)

**Project:** Hospital Appointment Management Website

### Aim

To refactor a non-semantic hospital webpage using HTML5 semantic elements and improve accessibility by implementing proper labels, input types, keyboard navigation and form validation.

### Objectives

1. To understand semantic HTML5 elements.
2. To create a structured hospital webpage.
3. To develop an accessible patient appointment form.
4. To implement client-side form validation.
5. To conduct before-and-after accessibility audits.
6. To use Git feature branches and GitHub Pull Requests.

### Software Requirements

- Visual Studio Code
- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Web Browser

### Implementation

The website contains:

1. Header and navigation section.
2. Hospital introduction and hero section.
3. Medical services section.
4. About hospital section.
5. Doctor information section.
6. Patient appointment form.
7. Footer section.

### Accessibility Improvements

- Semantic HTML5 elements.
- Proper heading hierarchy.
- Accessible navigation.
- Skip navigation link.
- Descriptive image alternatives.
- Form labels and suitable input types.
- Keyboard navigation and visible focus.
- HTML5 validation.
- Screen-reader status messages.

### Git Commands

```bash
git init
git checkout -b feature/accessible-hospital-website
git add .
git commit -m "Add accessible hospital appointment website"
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin feature/accessible-hospital-website
```

Create a Pull Request from the feature branch into the main branch using GitHub.

### Result

The hospital appointment management webpage was refactored using semantic HTML5 elements. An accessible appointment form was implemented with suitable input types, labels and validation.

Before-and-after accessibility findings were documented in the accessibility audit report.

**Note:** Final screen-reader and automated audit results must be recorded after performing the actual tests.
