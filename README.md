
# MediCare Hospital – Appointment Management Website

A responsive and accessible hospital appointment management website developed using HTML5, CSS3 and JavaScript.

## Project Overview

This project demonstrates the refactoring of a non-semantic hospital webpage into a structured, accessible and responsive website.

## Features

- Modern hospital website design
- Semantic HTML5 structure
- Hospital services section
- Doctor profile cards
- Patient appointment booking form
- Accessible form labels
- HTML5 form validation
- Keyboard navigation support
- Responsive design
- Screen reader-friendly status messages
- Accessibility audit report

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Add the required images to the img folder.
4. Open index.html using Live Server.
5. Explore the hospital website and appointment form.

## Accessibility Features

- Semantic HTML5 elements
- Accessible navigation landmarks
- Skip-to-content link
- Logical heading hierarchy
- Alternative text for images
- Explicit form labels
- Keyboard focus indicators
- Required field validation
- Accessible status messages
- Reduced-motion support

## Git Workflow

Create a feature branch:

```bash
git checkout -b feature/accessible-hospital-website
```

Stage the changes:

```bash
git add .
```

Commit:

```bash
git commit -m "Refactor hospital website with semantic HTML and accessibility"
```

Push:

```bash
git push -u origin feature/accessible-hospital-website
```

Create a Pull Request on GitHub from the feature branch into main.

## Important Note

This is an academic front-end demonstration. The appointment form does not connect to a hospital database or transmit appointment requests. A secure backend is required for real patient bookings.
